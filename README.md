# Student Management System

A professional Student Management System developed using Java, JavaFX, JDBC, and MySQL.

## Features

- Admin authentication
- Student management
- Course management
- Grade management
- Database integration
- CRUD operations

## Technologies Used

- Java
- JavaFX
- JDBC
- MySQL

## Project Modules

1. Authentication Module
2. Student Management Module
3. Course Management Module
4. Grade Management Module

## Database

MySQL database is used for storing:

- Users
- Students
- Courses
- Grades

## How to Run

1. Install Java JDK
2. Install MySQL
3. Configure database
4. Run Main.java


## Purpose

This project demonstrates Java OOP concepts, database connectivity,
SQL operations, and real-world application development.
